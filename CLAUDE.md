# PawlyPaint (Flutter, Android/iOS)
- Run: `flutter run`. Test: `flutter test`. Lint: `flutter analyze`. Format: `dart format .`
- Lint rules: prefer_const_constructors, prefer_final_locals (analysis_options.yaml).
- No CI. Assets are generated by `tool/*.py`; don't hand-edit generated art or audio.
- Run `flutter test` and `flutter analyze` before saying a change is done.
- graphify: local graph in `graphify-out/` (gitignored), refreshed by git hooks after each commit. Use `graphify affected "X" --depth 1` for impact checks; `god-nodes` is noisy here (small app), so grep or read directly for specific lookups.
